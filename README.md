# Responsive Landing Page

## Task 01

A simple responsive landing page with an interactive navigation menu.

### Features

- Fixed navigation bar
- Navigation remains visible while scrolling
- Navigation changes style when scrolling
- Hover effect on menu items
- Smooth scrolling
- Responsive design for mobile and desktop
- Home, About, Services and Contact sections

## Files

- `index.html` - Website structure
- `style.css` - Website design and responsive styling
- `script.js` - Scroll interaction
- `README.md` - Project information
